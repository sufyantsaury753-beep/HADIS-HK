# Hadis Hukum Keluarga Islam (Fiqh al-Usrah & Mubadalah)

Web eksplorasi hadis-hadis hukum keluarga Islam dengan paradigma **Mubadalah (kesalingan)** dan **Maqashid asy-Syari'ah** — mengedepankan etika relasi setelah perkawinan, keadilan gender, dan martabat kemanusiaan.

🔗 **Akses Website**: [https://sufyantsaury753-beep.github.io/HADIS-HK/](https://sufyantsaury753-beep.github.io/HADIS-HK/)

---

## 🌿 Fitur Utama

1. **Navigasi 7 Siklus Kehidupan Berkeluarga**:
   - Pra-Nikah & Ta'aruf
   - Akad & Perjanjian Perkawinan
   - Keseharian & Kerja Domestik (*Khidmah al-Bayt*)
   - Finansial, Nafkah & Apresiasi Istri Bekerja
   - Keintiman, Seksualitas Berkeadilan & *Marital Consent*
   - Resolusi Konflik & Anti-KDRT
   - Pengasuhan Anak (*Tarbiyah & Keadilan Anak*)

2. **Komparasi Hermeneutika Ganda (Dual-Reading View)**:
   - *Split-Screen* di Desktop dan *Tab-Switcher* di Mobile.
   - Komparasi berdampingan: **Pemaknaan Fiqh Arus Utama (Konvensional)** vs **Pembacaan Mubadalah (Kesalingan)**.
   - Teks Arab berharakat font Amiri, translasi, audio bacaan, dan rubrik aplikasi nyata pasutri hari ini.

3. **Generator Kartu Kutipan (Quote Card Generator)**:
   - Ekspor gambar kutipan hadis dan pesan kesalingan ke format **Story (9:16)** dan **Post (1:1)**.
   - Pilihan 4 palet warna estetik (*Sage Emerald*, *Warm Sand*, *Terracotta*, *Dark Slate*).

4. **Kuis Refleksi Pasutri**:
   - Evaluasi mandiri 5 pilar sakinah dalam relasi nyata sehari-hari.

5. **5 Pilar Keluarga Sakinah**:
   - *Mitsaqan Ghalizhan, Zawaj, Mu'asyarah bil Ma'ruf, Tasyawur, dan Taradhin*.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Exporting**: html2canvas
- **Deployment**: GitHub Pages & GitHub Actions

# Pasang dependensi
npm install
